# Hedge-Updater

Public download page for **Hedge Ratio Calculator** updates.

Install the newest `.apk` from [Releases](https://github.com/Soulshifted/Hedge-Updater/releases/latest).
After that, the app checks `latest.json` here each time it opens and offers new versions itself.

This repo holds only the built app files and `latest.json`. The source lives elsewhere.
